Regla de Dependencia (Dependency Rule)

Las dependencias solo apuntan hacia adentro. Las capas externas conocen a las internas, nunca al revés. El Domain no importa nada del proyecto; solo define contratos (interfaces).

UI → Application → Domain ← Infrastructure (implementa interfaces del Domain)
